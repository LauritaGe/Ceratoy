# Brand Guide — Todo es verdad

## Concepto

Canal de "periodismo alternativo" que presenta noticias ficticias del pasado con la seriedad de un reportaje verificado. El nombre es irónico: todo se afirma como verdad, pero es ficción generada por IA.

## Inspiración

- [4rt.eu/pioneers](https://4rt.eu/pioneers/) — Archivo de fotografías vintage ficticias del siglo XIX
- Estética de archivo histórico + narrativa convincente
- Diferenciador: tono más conspiranoico / "filtraciones desclasificadas"

## Voz editorial

| Atributo | Descripción |
|----------|-------------|
| Tono | Serio, periodístico, sin humor explícito |
| Perspectiva | Tercera persona, voz de corresponsal |
| Época | Finales del siglo XIX — principios del XX |
| Temas | Ciencia imposible, arqueología, contacto cósmico, máquinas olvidadas |

## Categorías

- **Descubrimientos** — Hallazgos arqueológicos o científicos
- **Filtraciones** — Documentos "desclasificados"
- **Testimonios** — Relatos de testigos
- **Archivos** — Material de archivo recuperado

## Naming

- **Canal**: Todo es verdad
- **Eslogan**: Donde todo es verdad, nada lo es
- **Slug posts**: `{tema}-{lugar}-{año}` (ej. `camara-invisibilidad-budapest-1898`)

## Disclaimer (obligatorio)

> Contenido 100% ficticio. Generado con inteligencia artificial. No representa hechos reales.
